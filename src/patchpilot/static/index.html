How it works

Model routing
With the model field empty, the small model is used only for one file with at most 20 changed lines and nothing that looks risky, such as passwords, SQL, eval, subprocesses or threads. Everything else goes to the large model.
Token and cost tracking
Each result shows the model, why it was used, tokens, cached tokens, time and cost, with a total for this visit. Costs are calculated for Claude models and shown as unknown for other providers.
Caching
Claude requests mark the instructions for prompt caching, although short ones may be too small to be cached. The command-line tool can also reuse replies to identical requests. This website does not, so that it keeps none of your code.
Evaluation
The project includes 26 small functions, each with one planted bug, and a harness that measures bugs caught and cost. Only a two-case trial has run so far, so there are no benchmark results yet.
Your API key
It is sent to this app, used to call the provider you chose, and then discarded. The app does not write it to disk or to its logs.
